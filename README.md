# 🌐 CrediChain

**CrediChain** es una **dApp de gestión de créditos descentralizada** que permite a solicitar, aprobar o rechazar créditos de manera transparente, registrando la información tanto en una base de datos tradicional como en la **blockchain de Ethereum (Holesky Testnet)**.  

Este proyecto integra **Frontend (Angular)**, **Backend (Spring Boot WebFlux)** y **Smart Contracts (Solidity)** para ofrecer una solución académica y funcional en el ámbito fintech descentralizado.

---

## ✨ Características principales
- Solicitud de créditos desde la aplicación web.
- Aprobación y rechazo de créditos desde el panel de administrador.
- Registro de contactos para gestionar transacciones.
- Historial de créditos y últimas solicitudes registradas.
- Interacción con **Ethereum (Holesky)** para validar y consultar transacciones en la blockchain.
- Arquitectura basada en **microservicios** con un backend reactivo y un frontend moderno.

---

## 🚀 Tecnologías utilizadas

### 🔹 Frontend
- **Angular 17**
- **TypeScript**
- **TailwindCSS**
- Integración con **Ethers.js** para interactuar con Ethereum.

### 🔹 Backend
- **Java 17**
- **Spring Boot 3 (WebFlux)**
- **R2DBC con PostgreSQL**
- **Lombok**
- **Maven**

### 🔹 Blockchain
- **Solidity**
- **Remix IDE / Hardhat**
- **Ethereum Holesky Testnet**
- **Metamask** para gestión de cuentas y transacciones.
- **Etherscan Holesky** para consulta de contratos y operaciones.
